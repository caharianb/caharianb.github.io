Internal platforms & systems

Employee Portal / HRIS

In production

The primary internal platform: leave and overtime workflows, a configurable approval-routing engine, and HR administration. Built with a system-wide feature-toggle framework so every module can be switched on per deployment, a drag-and-drop dashboard builder, per-user theming, and an embedded learning module. It's the foundation the commercial product grew out of.

FlaskSQLAlchemySQL ServerIIS

IT Inventory & Service Desk

In production

Asset tracking with a full help-desk module — multi-assignee tickets, asset linking, grouped dashboards and activity logging — plus a live monitoring module that pings devices in the background and shows green/red status, records up/down events, and keeps an incident log with severity, duration and printable reports.

FlaskSQL ServerBackground workersICMP / TCP checks

Learning Management System

In production

A training platform wired into the employee portal with single sign-on — the portal mints a signed, short-lived token, the LMS verifies it and auto-provisions the user — backed by directory authentication. Handles courses, quizzes and learner tracking.

FlaskLDAPSSigned SSO tokens

Document Archive

Recent build

A standalone records-archive service built from scratch, with a four-tier role model (employee, uploader, archive admin, system admin) and a request workflow covering photocopy-versus-borrow, page scope and return dates. Directory-backed auth with a local-account fallback.

FlaskSQL ServerLDAPSRole-based access

Data & infrastructure

Electricity-market data tools

Tooling

A Python toolchain for the Philippine wholesale electricity market: a client that pulls settlement data over mutual-TLS SOAP web services and parses the binary payloads to CSV and SQLite, wrapped in a desktop GUI. Paired with a real-time compliance dashboard featuring a price forecast with a confidence band and an accuracy scorecard against a naive baseline.

PythonDashTkinterSOAP / mutual-TLSSQLite

Network switch deployment tool

Tooling

A desktop app that generates and pushes switch configurations across Avaya, Ruckus and Cisco hardware — template placeholder substitution, a VLAN-port assignment grid pre-filled from templates, and a paced serial-console push. Packaged as a standalone executable. Built to support a redundant dual-core network redesign.

PythonTkinterSerial consolePyInstaller

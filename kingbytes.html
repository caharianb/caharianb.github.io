Products

Flagship SaaS

Kaboan

Commercial

A multi-tenant employee portal sold as a product — a clean-room rebuild of the internal HRIS I run every day, re-architected to be self-hosted and sellable. Per-tenant isolation, flexible authentication (local, directory, or hybrid), a two-level navigation model, and a dashboard where customers assemble their own stat, table, chart and list widgets from a safe data-source catalog. A two-tier admin model separates the vendor console from each customer's own system administration.

Platform

Ugnay

In development

A business-agnostic management platform built on three primitives — a money ledger, user-defined record types with flexible fields, and a due-dates layer — so a rental business, a lending operation and a retailer can all run on the same engine. It ships with template workspaces (Rental, Lending, Retail, or start blank) you copy in at setup, plus a self-service directory/SSO module for enterprise sign-on with per-tenant encrypted credentials.
